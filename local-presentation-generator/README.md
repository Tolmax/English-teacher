# Локальный генератор презентаций

Автономная Windows-программа для учителя. Она открывается в браузере, принимает список английских слов и создаёт PPTX-презентацию со словарными карточками, транскрипцией, подсказками и изображениями через OpenAI API.

## Что умеет

- принимает название презентации, класс/группу и список английских слов;
- создаёт карточки: слово, транскрипция, русская подсказка и промпт для картинки;
- генерирует изображения для карточек через OpenAI Image API;
- собирает готовый `.pptx`;
- даёт скачать презентацию из браузера;
- показывает уведомление, что генерация началась;
- автоматически повторяет временно упавшие запросы OpenAI при ошибках `429`, `500`, `502`, `503`, `504`;
- умеет открыть папку с готовыми презентациями;
- очищает старые временные картинки и файлы скачивания старше 30 дней.

## Установка на компьютер

Для установки используется архив:

```text
local-presentation-generator-install.zip
```

Полный архив уже содержит portable PHP в папке `runtime\php`, поэтому на
компьютере пользователя обычно не нужно отдельно устанавливать PHP или XAMPP.

Шаги:

1. Распакуйте архив `local-presentation-generator-install.zip` в любую удобную папку.
2. Откройте распакованную папку `local-presentation-generator`.
3. Запустите файл `install.bat`.
4. Установщик скопирует программу в папку пользователя:

```text
%LOCALAPPDATA%\EnglishPresentationGenerator
```

5. На рабочем столе автоматически появится ярлык:

```text
Генератор презентаций
```

6. Дальше программу нужно запускать именно этим ярлыком.

При повторном запуске `install.bat` установленная копия обновляется. Если в установленной программе уже есть файл `.env`, установщик его не перезаписывает: ключ OpenAI, порт и локальные настройки сохраняются.

## Запуск

После установки:

1. Дважды нажмите ярлык `Генератор презентаций` на рабочем столе.
2. Откроется страница:

```text
http://127.0.0.1:8010
```

3. Введите название презентации.
4. При необходимости укажите класс или группу.
5. Вставьте английские слова: по одному на строку, через запятую или через точку с запятой.
6. Нажмите `Сгенерировать PPTX`.
7. Дождитесь завершения.
8. Скачайте готовую презентацию.

Ограничение: до 20 слов за один запуск. Для большого списка лучше сделать несколько презентаций.

## OpenAI API

Настройки лежат в файле:

```text
%LOCALAPPDATA%\EnglishPresentationGenerator\.env
```

Пример:

```env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4.1-mini
OPENAI_IMAGE_MODEL=gpt-image-2
APP_PORT=8010
```

Если `OPENAI_API_KEY` уже указан в `.env`, поле ввода ключа на странице не показывается.

Если ключа нет, программа покажет поле `OpenAI API key`. Можно использовать ключ только для текущей генерации или поставить галочку `Сохранить ключ на этом компьютере`.

## Требования

В полном установочном архиве PHP уже лежит внутри программы. Если архив
собран без папки `runtime\php`, на компьютере должен быть PHP 8+ с расширением
`zip` (`ZipArchive`).

Программа ищет PHP в таком порядке:

1. portable PHP внутри программы:

```text
runtime\php\php.exe
```

2. старый portable-вариант внутри программы:

```text
php\php.exe
```

3. PHP в папке:

```text
C:\php\php.exe
```

4. PHP из XAMPP:

```text
C:\xampp\php\php.exe
```

5. PHP из системного `PATH`.

Если PHP не найден или в нём не включено расширение `zip`, программа покажет
понятное сообщение и не будет молча зависать.

## Где лежат результаты

Готовые PPTX:

```text
storage\output
```

Картинки карточек:

```text
storage\images
```

Файлы для скачивания из браузера:

```text
public\downloads
```

На странице генератора есть кнопка `Открыть папку с презентациями`.

## Удаление программы

В распакованной папке есть файл:

```text
uninstall.bat
```

Он удаляет ярлык с рабочего стола. Перед удалением установленной папки программа спросит подтверждение, потому что внутри могут лежать созданные презентации.

Для полного удаления нужно ввести:

```text
YES
```

## Создание установочного ZIP

После изменений в программе можно пересобрать установочный архив командой из папки `local-presentation-generator`:

```bat
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\make-package.ps1
```

Будет создан файл рядом с папкой проекта:

```text
local-presentation-generator-install.zip
```

В архив попадают:

- `install.bat`;
- `start.bat`;
- `uninstall.bat`;
- `.env`;
- `.env.example`;
- `public/`;
- `src/`;
- `scripts/`;
- пустые рабочие папки для результатов.

В архив не попадают старые сгенерированные презентации, картинки и файлы скачивания.

## Проверка после изменений

Минимальная проверка PHP-синтаксиса:

```bat
php -l public\index.php
php -l src\bootstrap.php
php -l src\openai.php
php -l src\pptx-presentation-builder.php
```

Боевой тест использует реальный OpenAI API и тратит запросы.
