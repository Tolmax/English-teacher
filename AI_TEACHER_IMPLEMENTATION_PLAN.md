# AI Teacher Implementation Plan

## Цель

Добавить ИИ-помощника учителя в существующую админку `/admin`, чтобы учитель мог готовить черновики рабочих листов, мини-тестов, объяснений, домашних заданий и планов уроков без отдельного модуля `/teacher`.

## Архитектурное решение

- Использовать текущую авторизацию админки и общий layout.
- Разместить раздел по адресу `/admin/ai-materials`.
- Хранить материалы в таблице `ai_teaching_materials`.
- Хранить будущие файлы источников и экспортов в таблице `ai_material_files`.
- Оставить генерацию OpenAI, экспорт DOCX/PDF и публикацию в публичный сайт для следующих задач фазы.

## Этапы реализации

1. База, модели и базовая админка: список, создание и редактирование черновиков.
2. Сервис генерации: подготовка prompt, вызов OpenAI, сохранение ответа и ошибок.
3. Редактор результата: правка сгенерированного текста и смена статуса.
4. Экспорт и файлы: DOCX/PDF, вложения, история файлов.
5. Связь с публичными материалами: публикация готового материала в нужный класс.

## Ограничения

- Не создавать отдельный кабинет `/teacher`.
- Не добавлять второй layout, вторую авторизацию или дублирующее меню.
- SQL держать только в моделях.
- Контроллеры должны работать через модели, валидаторы и редиректы после POST.
