Типографика

Системный гротеск, базовый размер от 16px, крупные заголовки для образовательного лендинга.

H1: Учим английский понятно

H2: Материалы для твоего класса

H3: Тема урока

Базовый текст: домашние задания, тренировки и ответы на вопросы собраны в одном месте.

Малый текст используется только для вторичной информации и не заменяет важный контент.

Радиусы

Карточки не превышают 16px, кнопки могут быть капсульными.

Тени

Лёгкие тени для отделения карточек, без heavy shadow.

Переходы

Короткие спокойные transitions для hover/focus, без сложных анимаций.

Кнопки

Типы из `common-elements.json`: primary, secondary, ghost, danger, link; размеры small, medium, large; состояния hover, active, disabled.

Поля ввода

Inputs, select, checkbox, radio, toggle и sliders из `common-elements.json`.
