# База знаний ИИ-помощника

Раздел `/admin/ai-knowledge` хранит источники для генерации ИИ-материалов: текстовые заметки, учебные файлы, конспекты и примеры.

## Что реализовано

- Таблица `ai_knowledge_categories` хранит категории источников.
- Таблица `ai_knowledge_sources` хранит метаданные, текстовое содержимое, категорию и архивный статус источников.
- Таблица `ai_material_knowledge_sources` хранит связи источников с ИИ-материалами.
- Источники можно фильтровать по режиму, типу, категории и статусу.
- Поиск работает по названию, описанию, тегам, имени файла и тексту источника.
- У каждого источника есть отдельная страница просмотра `/admin/ai-knowledge/{id}`.
- Файлы сохраняются в `uploads/ai-knowledge/`.
- На формах `/admin/ai-materials/create` и `/admin/ai-materials/{id}/edit` можно выбрать активные неархивные источники базы знаний.
- При создании копии ИИ-материала копируются только активные и неархивные источники оригинала.

## Категории

Стартовые категории:

- `Vocabulary`
- `Grammar`
- `Speaking`
- `Reading`
- `Writing`

Категория у источника необязательная: старые источники без категории продолжают работать.

## Использование источников при генерации

Task 3 Phase 6 подключил локальный fallback-контекст:

- при генерации ИИ-материала берутся только источники, выбранные в форме материала;
- учитываются только активные и неархивные источники;
- draft, архивные и отсутствующие записи игнорируются;
- в prompt попадают название, тип, описание, теги и ограниченный фрагмент `extracted_text`;
- действует лимит на один источник и общий лимит контекста;
- очевидные секреты вроде `OPENAI_API_KEY`, `Bearer ...` и `sk-...` маскируются;
- если источники не выбраны, генерация работает как раньше;
- `openai_file_id` и `vector_store_id` остаются подготовкой к будущему OpenAI file search/vector store.

## Важно

- Архивирование не удаляет файл физически.
- OpenAI file search/vector store пока не подключены.
- Файлы и тексты источников не отправляются в OpenAI автоматически вне существующего сценария выбранных источников.
