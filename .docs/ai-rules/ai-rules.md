# AI Rules

## Главный принцип
AI работает только в рамках текущего проекта, текущего стека и текущей архитектуры.

## AI не должен
- менять стек
- предлагать новые библиотеки без запроса
- переписывать рабочий код целиком без причины
- добавлять сложные абстракции
- переходить на другой стиль кода
- смешивать несколько задач в одном шаге

## AI должен
- сначала анализировать текущую документацию
- работать только в рамках текущей фазы
- перечислять, какие файлы будут изменены
- сохранять совместимость с текущей структурой
- объяснять, что было сделано
- указывать, что проверить вручную

## Формат ответа AI
1. Краткий план
2. Изменяемые файлы
3. Реализация
4. Что проверить вручную
5. Следующий логичный шаг

## Ограничения
- не делать рефакторинг без явной необходимости
- не менять unrelated code
- не внедрять функционал за пределами phase document
