# Codex Context Rules

## Перед задачей

1. Прочитай `AGENTS.md`.
2. Прочитай `.docs/project-status.md`.
3. Прочитай только релевантные документы по задаче.
4. Если есть `TASK.md` — считай его текущим рабочим заданием.

## Во время задачи

- Не держи важные решения только в чате: фиксируй их в `.docs/project-status.md`, phase-файлах, reports или dev-log.
- Не расширяй scope без причины.
- Если видишь несоответствие между документацией и кодом — сообщи и предложи, что считать источником истины.
- Если менялась БД — проверь необходимость обновления `.docs/database-schema.md` и `database/schema.sql`.

## После задачи

- Кратко перечисли изменённые файлы.
- Укажи, как проверен результат.
- Обнови `.docs/project-status.md`, если изменился этап, текущая фаза, TASK, риски или следующий шаг.
