# Architecture Rules

## Общие принципы
- Простая понятная архитектура
- Без лишних абстракций
- Каждая сущность имеет свою ответственность

## Controllers
- принимают запрос
- валидируют или вызывают validator
- вызывают model/service
- передают данные в template
- не содержат SQL

## Models
- работают с БД
- содержат SQL-запросы
- не рендерят HTML

## Templates
- отвечают только за отображение
- не содержат бизнес-логику
- не содержат SQL

## Services
- работа с файлами
- работа с графикой
- подготовка editor data
- вспомогательная бизнес-логика

## Validators
- проверяют входные данные
- возвращают понятные ошибки

## Routing
- маршруты описаны централизованно
- роутер не должен содержать бизнес-логики

## Общее:
- Controller принимает запрос и вызывает нужные функции
- Template не содержит бизнес-логики
- SQL не пишется внутри шаблонов
- Работа с файлами вынесена в отдельные функции/сервисы
- Editor.js хранится в JSON
- Все пути к файлам формируются централизованно от константы ROOT, которая определяет корень проекта и находится в config.php
- Все ссылки которые находятся внутри кода формируются от константы HOST, которая определяет url проекта и находится в config.php
- Ссылки в контенте, которые находятся в базе данных имеют полный путь к проекту, например https://localhost:444/about
