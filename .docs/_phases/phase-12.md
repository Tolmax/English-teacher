# Phase 12 — ИИ-презентации слов

## Цель

Учитель сможет ввести до 10 русских слов, получить ИИ-подбор английских слов с транскрипцией и картинками, сохранить результат как материал класса, открыть презентацию для просмотра, отредактировать и показать её на экране.

## Порядок реализации

- **Таск 1 — Хранилище и раздел ИИ-презентаций:** добавить модель, таблицу, маршруты админки и форму создания презентации по списку русских слов.
- **Таск 2 — Генерация словарных карточек через OpenAI:** по русским словам получить английское слово, транскрипцию, короткую подсказку и промпт/описание картинки; сохранить редактируемые данные.
- **Таск 3 — Сборка PPTX и экранный показ:** использовать образец `5a (1).pptx` как визуальный ориентир, генерировать `.pptx`, прикреплять его к обычным материалам и сделать HTML-режим показа для учителя.

## Публичная часть

| Маршрут | Описание |
|---------|----------|
| `/class/{slug}` | В блоке материалов класса показывает опубликованную презентацию как обычный материал с кнопкой открытия файла. |
| `/presentation/{id}` | Лёгкий экранный просмотр презентации в браузере, если материал опубликован или открыт учителем из админки. |

## Админка

| Маршрут | Описание |
|---------|----------|
| `/admin/ai-presentations` | Список ИИ-презентаций: класс, дата, статус, кнопки посмотреть/редактировать/опубликовать. |
| `/admin/ai-presentations/create` | Форма: класс, до 10 русских слов, короткая тема/название, режим публикации. |
| `/admin/ai-presentations/{id}/edit` | Редактирование карточек: русское слово, английское слово, транскрипция, описание картинки, порядок слайдов. |
| `/admin/ai-presentations/{id}/show` | Полноэкранный HTML-показ презентации для урока. |
| `/admin/ai-presentations/{id}/download` | Скачивание сгенерированного `.pptx`. |
| `/admin/materials` | Сгенерированная презентация отображается как обычный материал с прикреплённым PPTX-файлом. |

## База данных

| Таблица | Поля |
|---------|------|
| `ai_word_presentations` | `id`, `material_id`, `class_id`, `title`, `source_words`, `cards_json`, `pptx_file_id`, `status`, `model`, `response_id`, `created_at`, `updated_at` |
| `materials` | Используется существующая таблица для публикации презентации в материалах класса. |
| `material_files` | Используется существующая таблица для хранения PPTX-файла презентации. |

## Прототипы

**Страницы:**
- Подходящего прототипа для ИИ-презентаций нет.
- Для админки использовать строгую структуру существующих страниц `/admin/ai-materials`, `/admin/ai-tests` и дизайн-систему `prototypes/design-system/ui-design-system.html`.
- Для публичного вывода использовать текущий блок материалов страницы класса `prototypes/class.html`.

**Шаблон презентации:**
- Пользовательский образец: `c:\Users\Пресс-служба\Downloads\5a (1).pptx`.
- В рабочую версию проекта шаблон нужно перенести в серверную папку, например `storage/templates/word-presentation-template.pptx`.
- При инспекции образца найдено 26 слайдов, словарные слайды со словами `lion`, `leopard`, `crocodile`, `rhino`, `deer`, `cobra`, `elephant`, `camel` и блок упражнений.
- Для MVP не копировать всю структуру 26 слайдов один в один: использовать визуальный принцип карточек “картинка + английское слово + транскрипция”, чтобы презентация оставалась лёгкой.

## Что НЕ входит в фазу

- Полноценный онлайн-редактор PowerPoint внутри сайта.
- Автоматическая конвертация PPTX в PDF/PNG на сервере.
- Хранение OpenAI vector store или file search для презентаций.
- Генерация озвучки.
- Массовая библиотека внешних картинок с поиском по интернету.

## Важные правила

- Следовать `AGENTS.md`.
- Следовать `.docs/architecture-rules.md`.
- Следовать `.docs/specs/` для PHP, HTML, CSS, JS.
- SQL только в models, логика не в templates.
- Не хранить OpenAI API key в БД, шаблонах или JS.
- Не делать тяжёлую серверную зависимость от Node/LibreOffice: Timeweb должен запускать функцию на PHP-хостинге.
- PPTX должен быть обычным файлом материала, чтобы учитель видел его в привычном разделе “Материалы”.
- HTML-показ нужен для урока на экране, потому что браузер не умеет надёжно показывать PPTX без внешних сервисов.

## Definition of Done

- [ ] Учитель открывает `/admin/ai-presentations/create`, выбирает класс и вводит до 10 русских слов.
- [ ] Если слов больше 10 или поле пустое, форма показывает понятную ошибку и ничего не создаёт.
- [ ] В OpenAI-режиме система возвращает для каждого слова: русское слово, английское слово, транскрипцию и описание картинки.
- [ ] В mock-режиме создаются тестовые карточки без внешнего запроса.
- [ ] Учитель может отредактировать каждую карточку перед публикацией.
- [ ] После сохранения создаётся обычный материал класса и PPTX-файл в `uploads/materials/{materialId}/`.
- [ ] В `/admin/materials` презентация видна как материал с прикреплённым файлом.
- [ ] На странице класса опубликованная презентация видна в “Материалы к уроку”.
- [ ] Кнопка “Показать” открывает экранный HTML-режим с переключением слайдов.
- [ ] Кнопка “Скачать PPTX” отдаёт файл презентации.
- [ ] Проверен PHP-синтаксис изменённых PHP-файлов через `php -l`.
# Уточнение от 2026-06-21

В этой фазе учитель вводит слова сразу на английском языке. ИИ не переводит русские слова на английский, а помогает подготовить карточки: нормализует английское слово при необходимости, добавляет транскрипцию, короткую подсказку и описание картинки для будущей презентации.
