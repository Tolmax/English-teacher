# Phase 12 — ИИ-презентации слов

**Дата:** 2026-06-21

## Что сделано

- Добавлен раздел админки `/admin/ai-presentations` для создания, редактирования, удаления, показа и скачивания ИИ-презентаций слов.
- Создано хранилище `ai_word_presentations` для карточек презентации, статуса, связи с классом, PPTX-файлом и служебным материалом.
- Реализована генерация карточек по английским словам: слово, транскрипция, подсказка и описание картинки через OpenAI/mock-режим.

- Реализована сборка `.pptx` на PHP без Node, LibreOffice и внешних серверных пакетов.
- Добавлен HTML-плеер презентации с кнопками назад/вперёд, стрелками клавиатуры и полноэкранным режимом.
- Доработано удаление презентаций: удаляются связанные записи, PPTX, картинки и папка `uploads/materials/{materialId}`; если папку держит OneDrive/Windows, учитель получает предупреждение.

## Кратко

В проекте появился отдельный инструмент учителя для подготовки словарных презентаций. Учитель вводит до 10 английских слов, получает карточки с транскрипцией, подсказками и описаниями изображений, собирает презентацию с картинками в PPTX, скачивает её или показывает прямо из браузера. По итоговому решению презентации не выводятся на странице класса как ученический материал: они остаются в админке и используются учителем для демонстрации на уроке.

---

## Описание проблемы

До Phase 12 учитель мог создавать ИИ-тесты и материалы, но не мог быстро собрать демонстрационную презентацию по набору слов. Не было отдельного хранилища карточек, сборки PPTX, генерации изображений для слайдов и удобного HTML-режима показа на экране.

---

## Схема решения

Решение встроено в существующую MVC-структуру без фреймворков. Модель `ai-word-presentation.php` хранит презентации и карточки в JSON, валидатор проверяет класс, название и список слов. Контроллеры `/admin/ai-presentations/*` разделены по действиям: список, создание, редактирование, генерация карточек, сборка PPTX, показ, скачивание и удаление.

Генерация карточек вынесена в сервис `ai-word-presentation-generator.php`, генерация картинок — в `ai-word-presentation-images.php`, сборка PPTX — в `pptx-presentation-builder.php`. Файлы презентаций и картинки сохраняются в стандартную структуру `uploads/materials/{materialId}/`, но создаваемый материал имеет `is_published = 0`, чтобы презентация не попадала на страницу класса. Публичный маршрут `/presentation/{id}` оставлен как отдельное окно показа для учителя, а доступность определяется статусом самой презентации.

От первоначального плана изменено два важных пункта: учитель задаёт слова сразу на английском, а готовая презентация не публикуется ученикам на странице класса. Также добавлены индикаторы долгой генерации, защита от повторной перегенерации карточек и полноэкранный режим HTML-плеера.

## Acceptance criteria

- [x] Учитель открывает `/admin/ai-presentations/create`, выбирает класс и вводит до 10 английских слов.
- [x] Если слов больше 10 или поле пустое, форма показывает понятную ошибку и ничего не создаёт.
- [x] В OpenAI-режиме система возвращает для каждого слова английское слово, транскрипцию, подсказку и описание картинки.
- [x] В mock-режиме создаются тестовые карточки без внешнего запроса.
- [x] Учитель может отредактировать каждую карточку перед сборкой презентации.
- [x] После генерации карточек повторная кнопка генерации скрывается и не перезаписывает уже созданные карточки.
- [x] После генерации карточек доступна только кнопка “Собрать презентацию”.
- [x] При сборке создаются PNG-картинки в `uploads/materials/{materialId}/images/`.
- [x] PPTX-файл сохраняется в `uploads/materials/{materialId}/`.
- [x] Для PPTX создаётся запись в `material_files`.
- [x] `ai_word_presentations.material_id` и `ai_word_presentations.pptx_file_id` обновляются.
- [x] После сборки статус ИИ-презентации становится `published`.
- [x] После сборки появляются действия “Показать”, “Скачать PPTX” и “Открыть в отдельном окне”.
- [x] `/admin/ai-presentations/{id}/download` отдаёт сгенерированный `.pptx` только после авторизации.
- [x] `/admin/ai-presentations/{id}/show` открывает HTML-режим показа для учителя.
- [x] HTML-режим показа содержит слайды по карточкам: картинка, английское слово, транскрипция и подсказка.
- [x] В HTML-показе работают кнопки “Назад” и “Вперёд”, клавиши стрелок и полноэкранный режим.
- [x] `/presentation/{id}` открывает отдельный HTML-показ для готовой презентации.
- [x] Готовая презентация не отображается на странице класса, потому что это инструмент учителя, а не тест для ученика.
- [x] При удалении презентации удаляются связанные записи, PPTX, картинки и папка материала, если её не удерживает внешний процесс.
- [x] Все строки в шаблонах выводятся через `e()`, числовые ID приводятся к `(int)`.
- [x] Runtime-файлы синхронизированы в `deploy/`.
- [x] PHP-синтаксис изменённых PHP-файлов проверен через `php -l`.
