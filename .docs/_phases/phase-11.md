# Phase 11 — Шаблоны ИИ-тестов

## Цель

Учитель сможет выбирать один из нескольких шаблонов теста при генерации или ручном создании ИИ-теста, а ученик по-прежнему будет видеть простой единый экран “Тест”.

## Порядок реализации

- **Таск 1 — Модель шаблонов тестов:** добавить хранение выбранного шаблона у ИИ-материала/теста и централизованный список доступных шаблонов.
- **Таск 2 — Выбор шаблона в админке:** добавить понятный выбор шаблона на `/admin/ai-materials`, показать краткие подсказки и сохранить выбор при создании теста.
- **Таск 3 — Генерация и ручные заготовки по шаблону:** адаптировать OpenAI/mock/manual-режим под выбранный шаблон и проверить публичное прохождение теста.

## Публичная часть

| Маршрут | Описание |
|---------|----------|
| `/ai-tests/{slug}` | Показывает опубликованный тест ученику в прежнем простом интерфейсе без усложнения шаблонами. |
| `/class/{slug}` | Показывает опубликованный тест как обычный “Тест” в секции “Пройти тест”. |

## Админка

| Маршрут | Описание |
|---------|----------|
| `/admin/ai-materials` | Учитель выбирает класс, тему, заметки и шаблон теста перед генерацией. |
| `/admin/ai-materials/generate-test` | POST-действие создаёт тест с учётом выбранного шаблона. |
| `/admin/ai-tests/{id}/edit` | Редактор показывает тип шаблона справочно и даёт учителю проверить/исправить вопросы. |

## База данных

| Таблица | Поля |
|---------|------|
| `ai_teaching_materials` | добавить/использовать `test_template` или аналогичное поле для выбранного шаблона генерации |
| `ai_interactive_tests` | добавить/использовать `template_key` или аналогичное поле для связи готового теста с шаблоном |

Если будет достаточно хранить шаблон только в одной из существующих таблиц без дублирования — выбрать самый простой вариант и описать его в миграции.

## Шаблоны тестов

Минимальный набор для фазы:

- `quick_check` — быстрый тест: 10 вопросов, 2 варианта ответа.
- `vocabulary` — словарный тест: перевод, значение, употребление слов по теме.
- `grammar_gap` — грамматический тест: предложение с пропуском и выбор правильной формы.
- `reading_true_false` — короткий текст и утверждения True/False.
- `mixed` — смешанный тест: лексика, грамматика и понимание темы.

Все шаблоны должны приводиться к текущему публичному формату: вопрос, два варианта ответа, один правильный вариант.

## Прототипы

**Страницы:**
- `prototypes/admin/dashboard.html` → общий ориентир строгой админской сетки и карточек.
- `prototypes/design-system/ui-design-system.html` → дизайн-система форм, кнопок и подсказок.

Отдельного прототипа для шаблонов тестов нет. Вёрстку делать на существующих классах формы `/admin/ai-materials`, без новых визуально тяжёлых блоков.

**Assets:**
- CSS: `assets/css/base/`, `assets/css/blocks/`, `assets/css/sections/prototype-pages.css`.
- JS: `assets/js/main.js`, `assets/js/modules/confirm-action.js`, `assets/js/modules/ai-test.js`.

## Что НЕ входит в фазу

- Не менять публичный интерфейс ученика на разные сложные layouts для каждого шаблона.
- Не добавлять личные кабинеты учеников, пароли классов или учётные записи учеников.
- Не добавлять больше двух вариантов ответа в этой фазе.
- Не подключать внешние UI-библиотеки, React/Vue, Tailwind или CDN.
- Не делать OpenAI vector store/file search в этой фазе.

## Важные правила

- Следовать `AGENTS.md`.
- Следовать `.docs/architecture-rules.md`.
- Следовать `.docs/specs/` для PHP, HTML, CSS, JS.
- SQL только в models, логика не в templates.
- Шаблоны тестов хранить централизованно, чтобы не размазывать правила генерации по контроллерам и шаблонам.
- Для ученика название теста остаётся простым: “Тест”.

## Definition of Done

- [ ] На `/admin/ai-materials` есть выбор шаблона теста с понятными названиями.
- [ ] При генерации теста выбранный шаблон сохраняется в БД.
- [ ] OpenAI/mock-генерация получает инструкции, соответствующие выбранному шаблону.
- [ ] Ручной режим создаёт заготовку вопросов, соответствующую выбранному шаблону.
- [ ] `/admin/ai-tests/{id}/edit` показывает, по какому шаблону создан тест, и позволяет редактировать вопросы.
- [ ] На странице класса тест по-прежнему отображается как “Тест”, без технического названия шаблона.
- [ ] Публичное прохождение теста работает для каждого шаблона: выбор радиокнопки, подсветка правильности, итоговый балл, повторное прохождение.
- [ ] `php -l` пройден для изменённых PHP-файлов.
- [ ] `deploy/` синхронизирован с runtime-изменениями.
