# Phase 11 — Шаблоны ИИ-тестов

**Дата:** 2026-06-20

---

## Что сделано

- Добавлен централизованный список шаблонов ИИ-тестов: `quick_check`, `vocabulary`, `grammar_gap`, `reading_true_false`, `mixed`.
- В БД добавлены поля `ai_teaching_materials.test_template` и `ai_interactive_tests.template_key` с безопасным значением по умолчанию `quick_check`.
- На `/admin/ai-materials` добавлен выбор шаблона перед созданием теста.
- Выбранный шаблон сохраняется у ИИ-материала и переносится в интерактивный тест.
- OpenAI prompt и ручной fallback-режим теперь учитывают выбранный шаблон.
- В редакторе `/admin/ai-tests/{id}/edit` показываются название, описание и правила выбранного шаблона.
- Runtime-файлы синхронизированы в `deploy/`.

---

## Кратко

После Phase 11 учитель может создавать ИИ-тесты не только в одном стандартном формате, а выбирать тип заготовки: быстрая проверка, словарный тест, грамматика с пропусками, чтение True/False или смешанный тест. Для ученика всё осталось простым: на странице класса и на странице прохождения это по-прежнему обычный “Тест”, без технических названий и лишних настроек.

---

## Описание проблемы

До этой фазы ИИ-тесты создавались по одному общему шаблону. Учитель не мог заранее выбрать, нужен ли словарный тест, грамматическая тренировка, проверка чтения или смешанный формат. Из-за этого генерация была менее управляемой, а ручной режим создавал одинаковые заготовки независимо от педагогической задачи.

---

## Схема решения

Решение разделено на три шага. Сначала добавлена инфраструктура шаблонов: единый PHP-сервис со списком шаблонов, поля в SQLite и миграция для текущей базы. Затем выбор шаблона подключён к админской форме создания теста и к сохранению интерактивного теста. После этого генератор тестов получил шаблонные инструкции: OpenAI prompt включает название, описание и правила выбранного шаблона, а ручной fallback создаёт разные заготовки вопросов для каждого типа.

Публичный интерфейс намеренно не менялся. Все шаблоны приводятся к существующему формату: 10 вопросов, два варианта ответа, один правильный вариант. Это сохраняет простоту для ученика и не утяжеляет сайт.
