## Короткий процесс Codex

1. Спланировать фазу:
   Используй `.docs/codex/commands/phase-init.md`.

2. Создать задачу:
   Используй `.docs/codex/commands/task-init.md` и выбери нужный таск из фазы.

3. Реализовать задачу:
   «Реализуй задачу из `TASK.md`. Следуй `AGENTS.md` и `.docs/specs/`.»

4. Закрыть фазу:
   Используй `.docs/codex/commands/phase-report-init.md`.

5. Обновить журнал:
   Используй `.docs/codex/commands/dev-log-update.md`.
