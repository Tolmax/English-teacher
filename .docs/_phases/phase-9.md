# Phase 9 — Тестовый деплой на Timeweb

## Цель

После этой фазы сайт можно безопасно загрузить на Timeweb, запустить тестовую версию, проверить окружение хостинга и понять, готов ли сайт к боевому использованию.

## Порядок реализации

- **Таск 1 — Чистый deploy-пакет:** проверить и стабилизировать папку `deploy`, включить только runtime-файлы сайта, исключить документацию, прототипы, рабочие TASK/phase-файлы и локальный мусор.
- **Таск 2 — Диагностика хостинга:** добавить защищённую страницу в админке, где учитель/разработчик видит состояние PHP, SQLite, writable-папок, `.env`, OpenAI-режима и базовых путей без раскрытия секретов.
- **Таск 3 — Инструкция и smoke-check:** подготовить короткую инструкцию Timeweb и чеклист проверки после загрузки: главная, класс, админка, загрузки, база, OpenAI/mock.

## Что НЕ входит в фазу

- Настройка DNS и покупка домена.
- Реальная загрузка файлов на Timeweb через FTP/SFTP из Codex.
- Хранение `OPENAI_API_KEY` в репозитории или в `deploy`.
- Миграция с SQLite на MySQL.
- Личный доступ ученика, пароли для страниц классов и усложнение публичной части.
- Автоматический CI/CD деплой.

## Важные правила

- Следовать `AGENTS.md`.
- Следовать `.docs/architecture-rules.md`.
- Следовать `.docs/specs/` для PHP, HTML, CSS, JS.
- SQL только в models, логика не в templates.
- Не показывать значение `OPENAI_API_KEY` в интерфейсе, логах или документации.
- Диагностика должна быть доступна только после `requireAuth()`.
- Не трогать файлы вне раздела «Файлы для создания или изменения» без явной необходимости.

## Definition of Done

- [ ] В `deploy/` лежат только файлы, необходимые для работы сайта на хостинге.
- [ ] В `deploy/` нет `.docs`, `prototypes`, `TASK.md`, phase/report-файлов и локальных временных файлов.
- [ ] Сайт умеет читать `.env` рядом с `index.php`.
- [ ] В `.env.example` перечислены нужные переменные для тестового запуска.
- [ ] `/admin/system-check` доступен только авторизованному учителю.
- [ ] `/admin/system-check` показывает PHP version, SQLite/PDO status, путь к базе, writable-статус `database`, `uploads`, `storage`, наличие OpenAI-ключа без раскрытия значения.
- [ ] После загрузки на Timeweb можно вручную проверить `/`, `/class/1`, `/extra-lessons`, `/admin/login`, `/admin/system-check`, `/admin/ai-materials`.
- [ ] Инструкция Timeweb описывает: куда загрузить `deploy`, как создать `.env`, какие права поставить на папки, как проверить сайт после загрузки.
- [ ] PHP-файлы, изменённые в фазе, проходят `php -l`.
