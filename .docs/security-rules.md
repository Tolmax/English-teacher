# Security Rules

## Валидация
- все входные данные валидируются
- текст очищается и нормализуется
- обязательные поля проверяются

## SQL
- только prepared statements
- без прямой вставки данных в SQL

## Output
- вывод в шаблонах экранируется

## Uploads
- проверка MIME type
- проверка расширения
- проверка размера файла
- безопасное имя файла
- запрет выполнения файлов из uploads

## Sessions
- безопасная работа с сессиями
- regenerate session id where needed

## Errors
- пользователю не показывать внутренние ошибки
- ошибки писать в logs
