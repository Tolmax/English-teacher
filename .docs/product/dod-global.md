# Global Definition of Done

Эти критерии применяются ко всем задачам проекта.

- [ ] Код соответствует tech stack (PHP 8, SQLite, PDO, нативный JS, чистый CSS)
- [ ] Код соответствует architecture-rules.md
- [ ] Код соответствует code-style.md
- [ ] Нет PHP ошибок и warnings
- [ ] Нет критических ошибок в консоли браузера
- [ ] Все формы валидируются — на клиенте и на сервере
- [ ] Изображения валидируются при загрузке (тип файла, размер)
- [ ] Имена загружаемых файлов санитизируются
- [ ] Все SQL-запросы через PDO с параметрами (без конкатенации переменных в запрос)
- [ ] Вёрстка по BEM, нет inline-стилей и inline-скриптов
- [ ] Интерфейс адаптивен (desktop + mobile от 320px)
- [ ] Шаблоны .tpl не содержат бизнес-логики
- [ ] Базовые сценарии проверены вручную
- [ ] Нет неиспользуемых файлов и мёртвого кода
