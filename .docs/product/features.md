# Feature Backlog

Это общий backlog проекта — зафиксированные планы на реализацию.
Не является планом разработки. Может расширяться и сокращаться.

## Подтверждённые фичи

### Базовый функционал

- Главная лендинговая страница учителя с фото и краткой информацией.
- Блок выбора класса на главной странице.
- Отдельная страница для каждого класса.
- Публикация домашнего задания на странице класса.
- Публикация актуальной темы урока или краткого плана занятия.
- Блок с информацией о дополнительных занятиях.
- Контактный или информационный блок для связи или записи на дополнительные занятия.

### Стандартный функционал

- Карточки классов с названием, кратким описанием и кнопкой перехода.
- Раздел "Материалы к уроку" на странице класса.
- Раздел "Тренировка по темам" с ссылками на упражнения или файлы.
- Раздел объявлений для класса.
- Блок частых вопросов для учеников.
- Простая админская часть для учителя, чтобы обновлять информацию без правки кода.
- Архив прошлых домашних заданий и материалов.
- Адаптивная версия для телефона.

### Расширенный функционал

- Интерактивные кнопки-вопросы на главной странице или странице класса.
- Мини-тесты или тренировочные задания прямо на сайте.
- Фильтрация материалов по темам: грамматика, лексика, чтение, аудирование.
- Календарь уроков, дедлайнов и дополнительных занятий.
- Отдельная форма заявки на дополнительные занятия.
- Загрузка файлов учителем: PDF, изображения, документы.
- Статусы материалов: новое, важное, повторение, контрольная.
- Личный кабинет ученика или доступ по паролю для классов.
